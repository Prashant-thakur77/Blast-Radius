# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Non-obvious documentation context

- **`pulse/`** is NOT the product — it is a sample/demo target app. All BlastRadius product code lives in `blastradius/backend/`.
- **`demo-workspace/pulse/`** is NOT in git history — it is generated by `scripts/seed_demo.sh`. It will not exist on a fresh clone.
- **`site/`** is a static demo site (not Next.js) — run locally with `python3 -m http.server -d site 8765`.
- **The three PR branches** (`pr-1-dashboard-copy`, `pr-2-session-epoch`, `pr-3-task-archiving`) exist only in `demo-workspace/pulse`, not in this repo's git history.
- **`bob_sessions/`** contains screenshots and session logs of every Bob task run during the hackathon — useful reference for expected Bob behavior.
- **`.bob/rules-blast-radius-reviewer/`** contains the active reviewer protocol. The skill file at `.bob/skills/blast-radius-review/SKILL.md` is the 9-step procedure.
- **ADRs for the sample app** live in `pulse/docs/adr/`, not in this repo's root `docs/`.
- **`blastradius/frontend/`** is the older Next.js 3D graph explorer (pre-hackathon) — it uses the REST API and is NOT the primary interface. The current interface is Bob + the MCP server.
